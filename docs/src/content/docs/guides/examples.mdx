Every preview runs the real package against local data, the site's public cities JSON file or a simulated async directory. Each one offers HTML / CDN and Package / ESM files, separately or as one complete document, and the copied code is tested in a browser exactly as shown.

The first examples cover a single option at a time; the later ones combine several: pills compose the single-selection API into a multiple selection, the command palette mixes sections, keyword filters, custom rendering and recent picks, and dependent fields narrow one search by another. The headless directory uses `createSearch` without the combobox, so its ARIA and keyboard behavior belong to the application.
